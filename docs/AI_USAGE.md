## What was fully AI-generated vs. what you designed/modified

**Fully AI-generated in this session** (candidate should treat as first
draft, not final):
- Migration file structure and column choices
- Test scaffolding and fake provider classes

**Decisions embedded in the AI's output that are engineering judgment calls,
not defaults** — these are the ones you should be able to defend without
notes, because they're the actual substance of the exercise:
- Recognising subscription revenue immediately rather than ratably over the
  term (see `docs/ARCHITECTURE.md`)
- The "claim via payout_id + DB unique constraint" idempotency mechanism,
  rather than e.g. Redis locks or a separate ledger-state machine
- Never releasing earnings on a provider timeout, only on a confirmed
  failure — the crux of "don't guess when you don't know"
- Refund reversals as new negative ledger rows, never mutating history
- Floor-division-plus-remainder for splitting pool cents, with the fairness
  trade-off written down rather than hidden
